# Project: Calculator

Building a browser-based calculator using Javascript, HTML, and CSS.

## Description

This is a calculator that runs in a web browser.

## Getting Started

### How to Use

The calculator only depends on being run in a modern web browser. You may use the provided Docker compose file to serve the site from a local nginx container and access it by visiting `localhost:8080` in your favorite web browser.
